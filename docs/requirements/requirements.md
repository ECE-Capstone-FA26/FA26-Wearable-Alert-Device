# System Requirements

## Required
1. Alarm button
2. Fall detection
3. Removal alert using heartbeat detection or skin resistance
4. Tiny blue/red LEDs for connection status
5. Haptic feedback for alert acknowledgement
6. Watch-sized physical size
7. Belt-clip attachment
8. 12-hour battery life
9. USB or preferably wireless charging
10. Queue events for transmission when outside Bluetooth range
11. Continuous audio recording with 20-second pre/post audio transmitted via Bluetooth

## Desirable
- GPS/elevation
- Occasional heart rate

## Not Implemented
- Gunshot detection
